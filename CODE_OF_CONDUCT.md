# Code of conduct

pogo follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, welcome newcomers, and keep discussions about the work.
Harassment, insults and personal attacks aren't tolerated anywhere in this project's spaces.

To report a problem, contact the maintainers privately through GitHub (the repository's
**Security → Report a vulnerability** form also reaches them confidentially). Reports are
handled promptly and discreetly.
